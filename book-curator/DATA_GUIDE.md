# 기존 도서 데이터 파일 안내

프로젝트 루트와 `lib/data/`의 기존 JSON 파일은 초기 기획과 디자인 참고를 위해 보관합니다. 현재 웹 앱은 이 파일들을 import하거나 런타임 데이터베이스로 사용하지 않습니다.

## 현재 데이터 흐름

```text
사용자 검색·취향 입력
  → Vercel 서버 API
  → 카카오 도서 검색 API
  → ISBN 기준 도서 ID 생성
  → 추천·레이스·북클럽·나의 기록에 사용
```

- 검색 결과의 표지·제목·저자·출판사·ISBN은 카카오 응답에서 가져옵니다.
- 추천은 여러 카카오 검색 결과를 합치고 최근 읽은 책을 제외한 뒤 3권을 고릅니다.
- 레이스 진도는 책 내용 질문 없이 사용자가 5% 단위로 직접 기록합니다.
- 레이스·북클럽의 사용자 활동 데이터만 Supabase에 저장합니다.

## 기존 파일을 수정해도 화면이 바뀌지 않는 이유

기존 JSON은 앱 번들에서 참조하지 않도록 분리했습니다. 따라서 파일에 책을 추가하거나 삭제해도 검색과 추천 결과에는 영향이 없습니다. 새 책은 카카오 도서 검색에 등록되어 있으면 별도 데이터 입력 없이 앱에서 검색할 수 있습니다.

## 변경 후 확인

```powershell
npm test
npm run preflight
```

테스트는 카카오 응답 정규화, 검색 실패 시 로컬 대체 금지, 추천 3권, ISBN 기반 레이스, 수동 진도 기록, 북클럽 공유를 확인합니다. 배포 전 검사는 런타임 코드에 기존 도서 파일이나 제거된 질문 API 참조가 다시 생기지 않았는지 검사합니다.
