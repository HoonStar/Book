# 도서 API 연동 가이드

앱은 카카오 책 검색 API와 연결돼 있습니다. `KAKAO_REST_API_KEY`가 있으면 카카오를 자동 사용하고, 키가 없거나 API가 일시 중단되면 내장 목록으로 안전하게 폴백합니다. `BOOK_SOURCE=local`을 명시하면 카카오 키가 있어도 로컬 검색만 사용할 수 있습니다.

## 1. 설계 — 왜 "전체 교체"가 아니라 "하이브리드"인가

| 데이터 | 담당 | 이유 |
|---|---|---|
| 제목·저자·ISBN·표지 (서지정보) | **외부 API** | 최신·정확, 검색 범위 무한 |
| 감성 태그·난이도·테마·퀴즈 (큐레이션) | **로컬 카탈로그** (`lib/data/*.json`) | 어떤 공개 API도 제공하지 않는 이 서비스만의 자산 |

추천 점수와 완독 레이스는 큐레이션 필드가 있어야 동작하므로, 외부 검색 결과가 카탈로그와 매칭되면(ISBN 우선, 없으면 제목+저자 근사 매칭) 자동 병합되어 추천·레이스가 가능해지고, 미등록 도서는 "외부" 배지와 함께 장르 반영 폴백으로 처리됩니다. 이 매칭 로직은 `lib/booksource.js`에 있고 테스트 9건으로 검증돼 있습니다.

## 2. 후보 API 비교 (한국 도서 기준)

| | 카카오 책 검색 | 알라딘 Open API | 네이버 책 검색 |
|---|---|---|---|
| 키 발급 | developers.kakao.com → 앱 생성 → REST API 키 (즉시) | aladin.co.kr/ttb → TTB 키 신청 (즉시~수시간) | developers.naver.com → 앱 등록 |
| **쪽수 제공** | ✕ | **○** (ItemLookUp의 itemPage) | ✕ |
| 표지 이미지 | ○ | ○ (고화질) | ○ |
| 무료 한도 | 넉넉함 (일 수만 건) | 일 5,000건 | 일 25,000건 |
| 어댑터 상태 | **구현 완료** | **구현 완료** (+쪽수 조회 함수) | 미구현 (필요 시 어댑터 1개 추가) |

**추천 조합:** 검색은 카카오(빠르고 한도 넉넉), 쪽수 보강은 알라딘 `aladinLookupPages(isbn13)`. 완독 기간 계산에 쪽수가 필수라서 알라딘 키는 결국 필요합니다.

## 3. 켜는 법 (코드 수정 없음)

1. 키 발급 후 Vercel → Settings → Environment Variables에 추가:
   ```
   BOOK_SOURCE=kakao  # 선택: 키가 있으면 생략해도 자동 활성화
   KAKAO_REST_API_KEY=발급받은키
   ALADIN_TTB_KEY=발급받은키   (쪽수 보강용, 선택)
   ```
2. Redeploy → `https://배포주소/api/health` 에서 `"book_source": "kakao"` 확인
3. 추천 탭 검색창에 아무 책이나 입력 → 카탈로그 매칭 도서는 "레이스 가능", 미등록 도서는 "외부" 배지

로컬 테스트: `.env`에 같은 값 넣고 `vercel dev`.

## 4. 카탈로그를 실데이터로 키우는 루트 (권장 순서)

1. **ISBN부터 채우기** — `books.json` 각 항목에 `"isbn": "97911..."` 추가 (알라딘/교보 상세페이지에 표기). ISBN이 있으면 외부 검색 ↔ 카탈로그 매칭이 100% 정확해집니다.
2. 쪽수를 `aladinLookupPages`로 검증 (또는 상세페이지 수기 확인)
3. 큐레이션 필드(감성 태그·난이도·퀴즈)는 DATA_GUIDE.md 기준으로 직접 작성 — 이게 심사에서 "AI가 못 베끼는 부분"입니다.

## 5. 확장 여지 (지금은 범위 밖, 구조는 준비됨)

- **카탈로그의 Supabase 이전**: `lib/booksource.js`에 `SupabaseSource`를 추가하면 books.json 없이 DB에서 직접 로드 가능 — 관리 화면을 붙일 때 가치가 생깁니다.
- **네이버 어댑터**: `normalizeNaver` 함수 + fetch 하나면 끝 (기존 어댑터 패턴 복사).
- 표지 이미지는 이미 응답에 `cover`로 내려오므로, 추천 카드에 표지를 붙이는 건 프런트 몇 줄이면 됩니다.
