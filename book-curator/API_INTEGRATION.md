# 카카오 도서 API 연동 가이드

이 앱의 모든 도서 기능은 카카오 도서 검색 API 하나를 사용합니다. 로컬 도서 목록이나 다른 도서 API로 자동 전환하지 않습니다.

## 적용 범위

| 화면·기능 | 카카오 API 사용 방식 |
|---|---|
| 최근 읽은 책 자동완성 | 제목·저자 통합 검색 |
| 취향 추천·새 추천·시간대 추천·대화 추천 | 입력 조건으로 후보를 검색한 뒤 중복을 제거해 3권 선정 |
| 완독 레이스 | ISBN이 확인된 카카오 도서만 방 생성 가능 |
| 북클럽 도서 공유 | 검색 결과의 카카오 도서 ID와 서지정보 사용 |
| 나의 독서 기록 | 입력한 제목이 카카오 검색 결과에 있는지 확인 |

카카오 응답의 제목, 저자, 출판사, 표지, ISBN을 서버에서 정규화합니다. 앱 내부 도서 ID는 `kakao:ISBN` 형식이므로 레이스와 북클럽이 같은 책을 안정적으로 가리킵니다.

## Vercel 설정

1. Kakao Developers에서 애플리케이션을 만들고 **REST API 키**를 확인합니다.
2. Vercel 프로젝트 → Settings → Environment Variables에 다음 값을 추가합니다.

   ```text
   KAKAO_REST_API_KEY=발급받은_REST_API_키
   ```

3. Production과 Preview에 적용한 뒤 Redeploy합니다.
4. `https://배포주소/api/health`에서 `book_source`가 `kakao`, `kakao_key`가 `configured`인지 확인합니다.
5. 추천 화면에서 책 제목을 입력했을 때 표지와 출판사가 표시되는지 확인합니다.

API 키는 브라우저 코드에 넣지 않습니다. Vercel 서버 함수가 인증 헤더를 붙여 카카오에 요청하므로 사용자 화면이나 네트워크 응답에 키가 노출되지 않습니다.

## 실패 시 확인 순서

- `KAKAO_REST_API_KEY` 이름의 철자와 값 앞뒤 공백을 확인합니다.
- 키가 JavaScript 키나 Admin 키가 아니라 REST API 키인지 확인합니다.
- 환경변수를 추가한 뒤 새 배포가 만들어졌는지 확인합니다.
- `/api/books?q=아몬드`가 200 응답과 `source: "kakao"`를 반환하는지 확인합니다.

카카오 API가 실패하면 앱은 오래된 로컬 목록을 보여주지 않고 잠시 후 다시 시도해 달라는 오류를 표시합니다. 이는 모든 화면에서 같은 실시간 출처를 사용하기 위한 의도된 동작입니다.
