# 나의 페이지 최종 기획·구현 명세

## 1. 프로젝트 개요

- 서비스명: NextBook
- 페이지명: 나의 페이지
- 구현 형태: 반응형 HTML/CSS/JavaScript 웹페이지
- 기준 자료: NextBook Stitch 화면 시안, 디자인 시스템, 제공된 캡처 이미지
- AI 모델 설정: `gpt-4o-mini`
- 환경변수: 루트 `.env`의 `OPENAI_API_KEY`, `OPENAI_MODEL`
- 현재 구현 경로: `nextbook-my-page/`

## 2. 최종 화면 구조

상단 탭과 본문 순서는 동일하게 유지한다.

1. 도장깨기
2. 독서 기록
3. 취향 분석
4. AI 추천

왼쪽 상단 브랜드 표기는 기존 `NextBook` 대신 `나의 페이지`로 표시한다. 브랜드를 클릭하면 페이지 상단으로 이동한다.

### 데스크톱 내비게이션

```text
나의 페이지 | 도장깨기 | 독서 기록 | 취향 분석 | AI 추천 | 알림 | 프로필
```

### 모바일 내비게이션

```text
도장 | 기록 | 취향 | 추천
```

## 3. 탭 인디케이터

- 초기 활성 탭: `도장깨기`
- 탭을 클릭하면 청록색 바가 해당 탭의 아래쪽으로 이동한다.
- 바의 너비는 탭 텍스트 너비에 맞춘다.
- 이동에는 짧은 CSS transition을 적용한다.
- 활성 탭은 청록색 글자와 `aria-current="page"` 상태를 함께 가진다.
- 창 크기가 변경되면 인디케이터 위치와 너비를 다시 계산한다.
- 구현 파일: `tab-indicator.css`, `app.js`

## 4. 디자인 기준

- 배경: 웜 크림 `#F4EFE6`
- 기본 글자: 딥 네이비 `#26323D`
- 주요 포인트: 청록 `#3F8DA6`
- 보조 포인트: 스카이 블루 `#8CDAFF`
- 보조 강조: 뮤트 퍼플 `#9273AE`
- 제목: `Space Grotesk` + 한국어 fallback
- 본문: `DM Sans`, `Noto Sans KR`
- 카드: 반투명 화이트, 얇은 테두리, blur, 부드러운 그림자
- 모서리: 카드 16~20px, 버튼 8~10px, 태그 999px
- 모바일 기준 폭: 360px 이상
- 터치 영역: 최소 44px

## 5. 도장깨기

### 목적

목표 독서량과 현재 성취도를 단계별 도장으로 시각화한다.

### 구성

- 제목: `이달의 스탬프 퀘스트`
- 월간 여정 표시
- 완독 권수별 도장 단계
- 완료 도장: 청록색 원형 체크
- 미완료 단계: 점선 원형과 잠금/미완료 아이콘
- 마지막 단계: `목표` 도장
- 현재 달성률: 예) `3 / 6권`, `50%`
- 진행률 바: 목표 대비 완료 비율
- 목표 조정 버튼: `목표 줄이기`, `목표 +1권`

### 동적 상태

- 목표 기본값: 6권
- 완료 권수 예시: 3권
- 목표 변경 시 도장 개수, 퍼센트, 진행 바, 메시지를 동시에 갱신한다.
- 목표는 최소 완료 권수 이상, 최대 20권으로 제한한다.

### 목표 미달 응원 메시지

- 50% 미만: `첫 도장들이 멋지게 쌓이고 있어요!`
- 50% 이상: `절반을 넘어 잘 가고 있어요!`
- 1권 남음: `마지막 한 권만 남았어요!`
- 보조 문구에는 남은 권수와 부담 없는 다음 행동을 표시한다.

### 목표 달성 상태

- 배지: `🏆 이번 달 퀘스트 완료!`
- 메시지: `목표를 모두 채웠어요!`
- 진행률: 100%
- 응원 영역은 완료용 금색 계열 강조로 전환한다.

## 6. 독서 기록

탭을 누르면 독서 기록 섹션으로 이동하고 입력 폼에 바로 포커스한다.

### 입력 순서

1. 날짜
2. 제목
3. 완독 후 나의 감상

### 입력 UI

- 날짜: date input
- 제목: 한 줄 텍스트 입력, 최대 80자
- 감상: textarea, 최대 500자
- 실시간 글자 수 표시: `0 / 500`
- 저장 버튼: `✓ 독서 기록 저장`
- 안내 문구: `읽은 책을 한 권씩 차곡차곡 쌓아보세요.`

### 저장 및 누적

- 저장된 기록은 새 목록의 최상단에 추가한다.
- 기존 샘플 기록과 사용자가 작성한 기록을 함께 표시한다.
- 누적 기록 수를 `4개의 기록`처럼 표시한다.
- 브라우저 LocalStorage 키: `nextbookReadingLogs`
- 새로고침 후에도 저장된 기록을 다시 렌더링한다.
- 저장 후 입력 폼은 초기화하고 날짜는 오늘 날짜로 되돌린다.
- 기록 데이터는 날짜, 제목, 감상, 생성 ID를 저장한다.

### 기록 필터

- `전체`
- `완독`
- `읽는 중`

## 7. 취향 분석

### 취향 지도

- 제목: `취향 분석`
- 장르별 비중을 도넛 차트와 가로 막대로 표시한다.
- 예시 비중: 소설 42%, 과학 28%, 에세이 18%, 인문 12%
- 데이터가 적을 경우 차트 대신 기록 유도 문구를 표시한다.

### 취향 분석 인사이트

- 제목: `취향 분석 인사이트`
- 최근 선택 장르와 독서 무드를 설명한다.
- 요즘의 취향
- 집중 시간
- 다음 탐색 장르
- `인사이트 새로 분석하기` 버튼
- 마지막 분석 시각 표시

## 8. AI 추천

### 화면 구성

- 제목: `AI 추천`
- 저장한 추천 도서 카드 4개
- 카드 정보: 제목, 저자, 장르, 무드, 추천 저장 상태
- `전체 보기` 버튼
- 저장/저장 해제 상태 제공

### 현재 카드 예시

- 삼체 — 류츠신
- 물고기는 존재하지 않는다 — 룰루 밀러
- 숨결이 바람 될 때 — 폴 칼라니티
- 우리가 빛의 속도로 갈 수 없다면 — 김초엽

## 9. OpenAI API 기준

정적 HTML에서 API 키를 직접 호출하지 않는다. 실제 OpenAI 연동 시 서버 API를 통해 호출한다.

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

### 구현 원칙

- API 키는 서버 환경변수에서만 읽는다.
- 브라우저 번들, 네트워크 응답, 콘솔 로그에 키를 노출하지 않는다.
- 모델은 `process.env.OPENAI_MODEL || "gpt-4o-mini"`로 설정한다.
- OpenAI Responses API 사용
- 사용자 개인정보 대신 통계화된 독서 데이터만 전송
- 요청 실패 시 기존 기록과 UI는 계속 사용할 수 있어야 한다.

### 인사이트 API 예시

`POST /api/my/insights`

```json
{
  "booksReadThisMonth": 3,
  "readingDays": 12,
  "monthlyGoal": 6,
  "topGenres": ["소설", "과학"],
  "moodTags": ["집중", "감동"]
}
```

정적 데모에서는 API 호출 대신 미리 정의된 인사이트 문구를 순환해 UI 동작을 보여준다.
