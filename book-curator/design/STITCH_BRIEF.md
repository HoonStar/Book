# 완독 레이스 — Google Stitch 디자인 브리프

**사용법:** stitch.withgoogle.com → New project → **Mobile** 선택 → 아래 [공통 지시문]을 먼저 붙여넣고, 이어서 화면 프롬프트를 **한 화면씩** 입력하세요. Stitch는 한 번에 한 화면씩 줄 때 결과가 가장 좋습니다. 마음에 드는 화면은 Figma로 내보내거나 스크린샷을 저에게 주시면 현재 코드(style.css)에 그대로 이식해 드립니다.

---

## [공통 지시문] — 매 화면 프롬프트 앞에 함께 붙여넣기

```
모바일 독서 앱 "완독 레이스"의 화면을 디자인해줘. 390px 모바일 기준.

무드: 도서관 대출카드 + 문고본. 아날로그 독서의 물성(도장, 티켓, 형광펜, 색지 메모)을
디지털로 옮긴 느낌. 유치하지 않게, 차분하고 정돈되게.

컬러 토큰 (반드시 이 값 사용):
- 잉크(본문/제목): #22303A
- 배경 종이: #F1F4F0 (쿨톤 종이색, 크림색 아님)
- 카드 배경: #FFFFFF, 테두리 #DCE3DC
- 포인트(도장 그린): #0E6B5C — 버튼, 배지, 스탬프
- 하이라이터 옐로: #FFD84D — 진도 바, 핵심 문구 밑줄 강조
- 노트 색지 4종: #F6F3EA(종이) #DFF2E9(민트) #FBF3D0(버터) #FBE4E6(로즈)

타이포: 제목·감성 문구는 세리프(고운바탕 느낌), 본문·UI는 산세리프(프리텐다드 느낌),
초대 코드 등 코드성 텍스트는 모노스페이스. 라운드 14px, 그림자는 아주 옅게.

톤앤매너: 문구는 존댓말, 짧고 다정하게. 이모지는 절제해서 사용.
```

## 화면 1 — 추천 입력 (홈)

```
독서 취향 입력 폼 화면.

상단: 원형 잉크 도장 로고(테두리만 있는 원 안에 "완독", 살짝 기울어짐) + 앱 이름
"완독 레이스", 부제 "같이 읽어야 끝까지 읽는다".
그 아래 세그먼트 탭 3개: [추천(활성)] [레이스] [서재].

폼(흰 카드 하나에 담기):
1. "최근 읽은 책 (최대 3권)" — 검색 인풋 + 아래로 자동완성 드롭다운이 열린 상태.
   드롭다운 항목: 책 제목 · 작가, 일부 항목에 초록 아웃라인 배지 "레이스 가능",
   외부 검색 결과 항목엔 회색 배지 "외부". 선택된 책은 버터색 알약 칩으로 표시(× 포함).
2. "선호 장르 (1~3개)" — 알약 칩 8개: 소설/자기계발/에세이/과학/역사/경제경영/인문/추리·스릴러.
   선택된 칩은 도장 그린 배경 + 흰 글자.
3. "현재 기분" — 칩 5개: 위로가 필요해/자극이 필요해/몰입하고 싶어/가볍게 쉬고 싶어/성장하고 싶어.
4. 슬라이더 2개 나란히: "하루 독서 시간 30분", "완독 목표 30일" (값은 그린으로 강조).
5. "독서 속도" 칩 3개: 느림/보통/빠름.
하단 풀와이드 CTA 버튼(도장 그린): "이번 달 안에 끝까지 읽을 3권 찾기".
```

## 화면 2 — 추천 결과

```
추천 결과 화면. 상단에 얇은 버터색 안내 배너(예: "목표 기간 내 후보가 부족해 45일로 완화했어요").

도서 카드 3장 세로 나열. 카드 구성:
- 1행: 세리프 제목 "미드나잇 라이브러리" + 작가·장르·쪽수(작은 회색), 우측 상단
  초록 아웃라인 배지 "레이스 가능".
- 한 줄 소개: 세리프체, 문장 뒤쪽 60%에 하이라이터 옐로가 칠해진 형광펜 밑줄 효과.
  예: "후회의 도서관에서 다시 고르는 인생".
- 추천 이유 2문장(회색 본문). 예: "'위로가 필요해' 기분과 소설 취향에 맞춰 골랐어요."
- 지표 행: "완독 D+12 · 하루 34쪽 · 매칭 87점" (숫자만 그린 볼드).
- 매칭 점수 진행 바(그린, 87%).
- 접힌 디스클로저: "왜 이 책인가 (점수 근거)".
- 풀와이드 그린 버튼: "이 책으로 완독 레이스 시작".
카드 3장 아래: 민트색 연계 추천 카드 "📚 다음 책 예약: 《달러구트 꿈 백화점 2》 — 1권이
잘 맞았다면 자연스럽게 이어 읽기 좋아요."
```

## 화면 3 — 레이스 보드

```
완독 레이스 현황판.

헤더 카드: 세리프 제목 "《아몬드》 완독 레이스", 메타 "손원평 · 264쪽 · 목표 21일 · 3명 참가".
그 아래 점선 테두리(그린)의 티켓 스타일 박스: "초대 코드  K7M2QF  [복사]" —
코드는 모노스페이스 크게, 자간 넓게.
그 아래 풀와이드 그린 버튼: "📖 50% 인증 퀴즈 풀기 (전부 맞혀야 도장!)".

참가자 카드 3장(순위순):
- 1행: "👑 지훈 [나]" (나 배지는 그린 알약) / 우측 "검증 50% · 시도 3회".
- 진도 바: 하이라이터 옐로의 사선 스트라이프 패턴, 50% 채움.
- 대출카드 도장 4개 가로 배치: 25/50은 그린 테두리에 살짝 기울어진 "찍힌 도장",
  75/100은 회색 점선의 빈 자리.
- 다른 참가자 카드엔 응원 이모지 버튼 행: 👏 🔥 🏃 📚 ☕.
하단 "응원 피드" 카드: "🔥 민지 → 지훈" 형식 3줄.
```

## 화면 4 — 인증 퀴즈 (모달, 2상태)

```
상태 A — 풀이: 모달 카드. 제목 "50% 인증 퀴즈", 부제 "《아몬드》 · 2문항 모두 맞혀야
도장이 찍혀요". 문항 2개, 각 4지선다 라디오(선택 시 민트 배경 + 그린 테두리).
하단 [닫기] [채점하기(그린)].

상태 B — 통과: 모달 중앙에 큰 원형 도장(그린 테두리, -10도 기울어짐, 안에 "50%"),
제목 "도장 획득!", 부제 "2/2 정답 — 진짜 읽고 계시네요." 버튼 [레이스 보드로].
실패 변형: 붉은 테두리 도장에 ✕, "아직이에요 (1/2)", "조금 더 읽고 다시 도전!
시도 횟수는 기록돼요." 버튼 [닫기] [다시 도전].
```

## 화면 5 — 서재 (감상 노트)

```
감상 노트 공유 화면.

상단 작성 카드: 제목 "감상 노트 남기기", 여러 줄 입력창(placeholder: "이 책이 왜
좋았는지, 어떤 문장이 남았는지 적어 보세요"), 아래 한 줄에 색지 스와치 4개(종이/민트/
버터/로즈 원형)와 스티커 6개(📖 🌙 🔥 🌿 💡 🫶), 그린 버튼 "노트 붙이기".

노트 피드: 색지 배경의 메모 카드들(좌상단 모서리만 각지고 나머지는 라운드 — 메모지 느낌).
카드 우상단에 스티커 이모지가 살짝 겹쳐 붙음. 본문 2~3줄, 하단 세리프 서명
"— 민지 · 《아몬드》". 색지 색은 카드마다 다르게.
```

## Stitch 결과물을 받은 뒤

1. 화면별 결과 중 마음에 드는 것을 **스크린샷 또는 Figma 링크**로 공유해 주세요.
2. 제가 현재 앱의 `style.css`(이미 같은 토큰 체계로 작성됨)에 차이점만 이식합니다 — 앱은 지금도 완성된 디자인으로 동작하므로, Stitch는 "더 나은 안이 나오면 채택"하는 업그레이드 단계입니다.
3. 발표자료에는 Stitch 시안과 실제 구현 화면을 나란히 놓으면 "기획 → 디자인 → 구현" 프로세스 증빙이 됩니다.
